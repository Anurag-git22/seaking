# Sea King Boating Safari - Devbag, Malvan

A minimal, modern, mobile-first frontend website for **Sea King Boating Safari**, a premier boating safari and ferry service located in Malvan, Maharashtra.

## Features

- **Ocean-Inspired Palette**: Deep Navy (`#0A192F`), Teal (`#0D9488`), Crisp White, and Sun/Sand accent (`#F59E0B`).
- **Typography**: Clean, modern sans-serif (*Plus Jakarta Sans*).
- **Concise Content**: Short headlines and one-line descriptions only.
- **Sections**:
  1. **Hero**: Full-width boat/backwater photo, title *"Sea King Boating Safari"*, tagline *"Backwaters. Dolphins. Island adventures."*, and direct "Call Now" & "WhatsApp" buttons.
  2. **Two Locations (Prominent)**:
     - **Location 1**: *Devbag, Malvan* - Near Mahapurush Mandir, Devbag, Malvan - 416606, Maharashtra (Daily 10:00 AM - 7:00 PM) + "Get Directions" Google Maps link.
     - **Location 2**: *Tarkarli Jetty, Malvan* - Near MTDC Water Sports Point, Tarkarli, Malvan - 416606, Maharashtra (Daily 8:00 AM - 6:30 PM) + "Get Directions" Google Maps link.
  3. **Experiences**: 5 signature tour cards:
     - *Tsunami Island*: water sports, jet ski, bumper and banana rides
     - *Devbag Sangam & Backwaters*: where the river meets the sea
     - *Dolphin Safari*: spot dolphins near the creek mouth
     - *Bhogwe Beach & Crocodile Point*: coastal excursions
     - *Mangrove Safari*: boat tours through mangrove channels
  4. **Why Us Strip**: Trust badge with `5.0 rating | 200+ reviews | Open 7 days`.
  5. **Gallery & Lightbox**: 8 high-resolution photos with interactive lightbox modal (prev/next navigation, keyboard ESC support).
  6. **Contact & Enquiry**: Direct phone, WhatsApp, Instagram links, and an instant enquiry form that formats booking requests for WhatsApp.
  7. **Footer**: Complete details for both Malvan boarding locations, hours, and quick links.
  8. **Mobile Sticky Bar**: Always-accessible bottom bar with "Call Now" and "WhatsApp" buttons for instant tap on smartphones.

## Setup & Running

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
