# Experience Images

This folder contains images for the new tour experiences. Please add the following images:

## Required Images (16:10 aspect ratio recommended)

1. **devbag-beach.jpg** - Devbag Beach: Calm golden shoreline
2. **seagull-island.jpg** - Seagull Birds & Island: Flocks of seagulls on the sandbank  
3. **mini-kerala.jpg** - Mini Kerala: Palm-fringed backwaters
4. **crocodile-point.jpg** - Crocodile Point: Rocky coastal viewpoint

## Fallback Behavior

If any image is missing, the card will display a soft teal-to-navy gradient background as a placeholder until the actual image is added.

## Image Guidelines

- **Aspect Ratio**: 16:10 (e.g., 1600x1000px) works best
- **Format**: JPG or WebP
- **Quality**: High quality but web-optimized (under 500KB per image)
- **Subject**: Authentic photos of the actual tour locations
